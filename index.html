What does this do?

If you need to use transparency, also have to match a particular solid colour at the same time, this is the tool for you.

By defining the base and background colours, you can calculate the nearest target colour and opacity.

Opacity is the alpha byte (0–255) used in #RRGGBBAA output. Colour channels are rounded to 8-bit values, so a perfect match to the base may not always be possible.
